# Plainer Files

Work with files in your Plainer workspace from a Claude conversation. Ask Claude to find a project note, read it, create a checklist, or edit a specific passage. For example, ask “Find Community Garden Agenda and add a task to book the room.” You can also ask Claude to delete a particular file.

Connect your own Plainer account and choose read-only access or editing access. The plugin sends file requests directly to Plainer’s hosted API. Plainer returns the requested file data to Claude and saves edits in your workspace. You can revoke the connection from Plainer’s Connections page. [Connect your account](https://plainer.app/connections)

The included Plainer Files skill explains how to select the right file, check its current revision, preserve surrounding content, and read back a saved edit. The plugin contains the skill and the remote connector configuration. It runs no local programs.
